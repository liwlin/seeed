## 二、关键接口、数据和行为

| 核对项目 | 必须确认的内容 | 实际结果/单位/库/证据 |
|---|---|---|
| 整板与 USB | 完整整板预连接，只接 USB；目标电脑能识别并上传 |  |
| Part 1 串口交接 | Twin 已断开；串口占用定位及恢复路径可重复 |  |
| OLED | I2C A4 SDA/A5 SCL；库/地址、ASCII 两行与重启 |  |
| LED | D4 普通数字输出，无硬件 PWM；闪烁计时及常亮/熄灭分支 |  |
| 蜂鸣器 | D5 数字输出；启动一轮次数/时长/间隔，结束停止 |  |
| 光线 | A6 ADC；Probe 读数方法、亮暗范围、方向，重叠时重测 |  |
| 声音 | A2 ADC；安静/发声范围与阈值依据，不当作已校准分贝 |  |
| M05 AND | 明亮安静、明亮大声、暗光安静不报警，暗光大声 LED 报警 |  |
| 按键与 M06 | D6；读法与必要处理；先恢复环境、仍保持、按键解除、再触发 |  |
| 持续异常按键扩展 | 若本班选择，声明并核对策略及执行顺序，另行验收；可能再触发不自动判故障 |  |
| 旋钮与 M07 | A0；映射/显示/实际比较值一致，不锁存，无按钮/光线继承 |  |
| 温湿度版本 | DHT11/D3 单线时序或 DHT20/I2C，实际型号及对应库先确认 |  |
| 气压版本 | BMP280 或 SPA06-003，在本套件走 I2C；单位与库来源 |  |
| 环境显示 | 温度、湿度、气压标签/单位、合理刷新间隔；先确认再 V1 |  |
| LIS3DHTR | I2C；库返回 XYZ 单位/范围、平放和倾斜读数、规则及恢复 |  |
| 姿态边界 | 0.7 非通用阈值；不能单独测 Yaw，不能作为建筑安全检测 |  |
| M10 协作 | 至少3个功能模块在同一规则/数据显示中协作；主控/USB不计 |  |

I2C 共用 A4 SDA/A5 SCL；本课没有 UART 传感器，USB 串口用于上传和调试。温湿度未知时不固定猜 D3 或 I2C；确认前不进入 M08 V1。

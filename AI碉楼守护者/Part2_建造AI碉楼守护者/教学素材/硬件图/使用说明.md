# Part2 硬件图使用说明

每关提供硬件实物识别图和板内接线示意，按本关主要模块高亮。网页可切换、看特写、放大和下载当前SVG。接线视图根据当前已选模块实时生成整体SVG，所有元件和已确认接口的线路同时显示。点击模块只改变高亮，其他元件与线路继续保留；勾选和取消模块会立即更新图示。

各模块接口与引脚口径见[传感器接口与引脚说明](传感器接口与引脚说明.md)。

## 课堂实际需要连接什么

本课程用完整 Grove Beginner Kit 整板。模块已通过PCB预连接，电脑用USB数据线连接Seeeduino Lotus即可。图中的其余线突出板内信号关系，不要求学生另接Grove线或拆板。照片是静态官方参考，不显示当前真板读数或程序运行状态。

## 照片与版本

主照片是Seeed官方新版实拍，原像素未修改，SVG只做位置标注和显示区域裁切。旧Parts.jpg是官方布局示意，不是实物照片；旧版温湿度/气压替代特写明确标注“旧版示意·非实拍”。

温湿度旧DHT11接D3，属于单线数字时序，需要DHT库按时序读取；新DHT20接I²C。版本未确定时模块仍显示，但不猜固定信号线；这不表示整板实际上未接好。气压旧BMP280、新SPA06-003均按本套件I²C表示，库和型号仍需课堂确认。

| 模块 | 本套件默认信号 |
|---|---|
| OLED显示屏 | I²C |
| LED指示灯 | D4 |
| 蜂鸣器 | D5 |
| 光线传感器 | A6 |
| 声音传感器 | A2 |
| 按键 | D6 |
| 旋钮电位器 | A0 |
| 温湿度模块 | 旧DHT11:D3；新DHT20:I²C；未确定先确认 |
| 气压模块 | I²C |
| 三轴加速度计 | I²C |

I²C共享信号为SDA=A4、SCL=A5。图中不把0x78/0x3C等设备地址写成接线脚，供电和公共地由PCB连接。

## 元件俯视接线图

接线图参考 Fritzing Breadboard View 的元件俯视和弯曲彩色线束表达，以自绘SVG展示主控、Grove插口、触点及模块外形。它是板内连接的等效展开，元件布局并非尺寸图，也不是已验证的外接电路。没有导入Fritzing零件库、安装软件或创建`.fzz`工程。

Grove线色：黄为Pin 1（I²C:SCL/A5，GPIO:本模块主信号），白为Pin 2（I²C:SDA/A4，GPIO:本任务未用），红VCC、黑GND。红黑仅说明板内供电与公共地，不要求外接电源；模块供电电压按实际套件规格。

光线模块只有A6板内信号线，VCC/GND注明PCB已接，图中不新增A6 Grove插口。温湿度版本待确认时保留模块示意，不画固定信号线。多I²C模块在同一图中接到共同SDA/SCL，按接线颜色与引脚标签识别。未知温湿度模块仍显示，版本未确认时只不画该模块的固定信号线，其他元件线路正常保留。

桌面和手机默认“适应画布”，完整显示所有元件与主板。需要查看触点细节时可选“原尺寸”并在图框中滚动，或打开“放大查看”；点“适应画布”恢复完整显示。切换焦点只改变高亮，不隐藏元件，不更改程序或控制实物。

## 网页实时绘图技术

网页采用原生JavaScript和SVG，不预存所有元件组合截图。hardware-catalog定义模块名称、接口类型和引脚，学习设置确定板卡版本；hardware-ui将当前已选模块组成spec，hardware-svg根据数量、接口位置及可用空间选择上、下、左、右槽位，让主板保持在绘图区中间，并计算元件与线路位置。勾选变化触发重新生成SVG并更新图框；点击焦点只改变轮廓与线条高亮。多I²C设备接到相同A5/SCL、A4/SDA源触点；A6仍为板内信号点。

只选一个模块时图示自然只有一个；两个及以上显示整体连接。下载SVG直接导出当前生成的图形，包括当前全部元件与线路。PNG/SVG素材只是教学导出，不是网页显示机制，也不表示已检测实物连接。绘图没有后台、LLM调用或额外依赖。


主板图按实物参考固定长宽比例；选择1个、2个或多个模块时主板形状和接口布局保持一致。新增的布线空间安排在主板外侧。网页缩放与SVG导出都保持比例。


元件较多时会利用主板上方和下方的空间；十个模块使用顶部三个、底部三个、左右各两个的环绕布局。默认完整显示，主板不会因为滚动画布或图片高度上限被截掉。点击模块只高亮，不改变当前布局。

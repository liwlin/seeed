# Part2 传感器接口与引脚说明

本说明用于 Part2 Mission Center 的硬件图、任务引导和教师讲解。课程使用完整 Grove Beginner Kit for Arduino 整板，板载模块已经通过 PCB 预连接；课堂实际只需要用 USB 数据线连接电脑与 Seeeduino Lotus 主控。

网页中的接线图是板内连接的等效展开，目的是让学生理解“模块走什么信号、到主控哪个引脚”。它不是拆板、外接线或重接线说明。

## 模块接口表

| 模块 | 课程默认接口 | 主控信号 | 课堂说明 |
|---|---|---|---|
| OLED 显示屏 | I2C | SDA A4，SCL A5 | 与其他 I2C 模块共享总线，用于显示文字和状态。 |
| LED 指示灯 | 普通数字输出 | D4 | 控制亮、灭、闪烁；板载 D4 不支持硬件 PWM 调光。 |
| 蜂鸣器 | 普通数字输出 | D5 | 用数字输出控制鸣叫、停止和节奏，不是 UART 设备。 |
| 按键 | 普通数字输入 | D6 | 读取按下和松开状态。 |
| 旋钮电位器 | 模拟 ADC 输入 | A0 | 读取连续模拟值；它是电位器，不是旋转编码器。 |
| 光线传感器 | 模拟 ADC 输入 | A6 | 读取光照强弱；A6 是整板内部信号点，不额外虚构一个外接 Grove 插口。 |
| 声音传感器 | 模拟 ADC 输入 | A2 | 读取声音强弱的模拟量，不是 UART 音频接口。 |
| 温湿度模块（旧版） | DHT11 单线数字时序 | D3 | 需要 DHT 库按时序读取，不能按普通按键输入处理，也不是 UART。 |
| 温湿度模块（新版） | I2C | SDA A4，SCL A5 | DHT20 走 I2C，不沿用旧版 DHT11 的 D3 接法。 |
| 温湿度版本未知 | 先确认版本 | 不固定 | 未确认前只提示“旧 D3 / 新 I2C”，不画固定信号线。 |
| 气压模块（旧版） | I2C | SDA A4，SCL A5 | 旧版 BMP280 在本套件课程中按 I2C 使用。 |
| 气压模块（新版） | I2C | SDA A4，SCL A5 | 新版 SPA06-003 在本套件课程中按 I2C 使用。 |
| 三轴加速度计 | I2C | SDA A4，SCL A5 | LIS3DHTR 在本套件中走 I2C，与 OLED、气压等模块共享总线。 |

## Grove 线色

| 颜色 | I2C 语境 | 普通 GPIO / ADC 语境 |
|---|---|---|
| 黄线 | SCL / A5 | 本模块主信号 |
| 白线 | SDA / A4 | 本课程多数 GPIO/ADC 模块未使用 |
| 红线 | VCC | VCC |
| 黑线 | GND | GND |

红线和黑线只说明模块供电与公共地已经由 PCB 连接。模块供电电压按套件模块规格理解，不把裸芯片的 3.3V 规格一律写成整板 Grove 口供电。

## USB 与 UART

USB 是电脑连接主控、CodeCraft 上传和串口调试的通道，不是传感器协议。

本课程十个板载模块中没有 UART 传感器。Seeeduino Lotus 的硬件串口为 D0/RX、D1/TX；USB 桥接与硬件 Serial 共享同一串口资源。课堂任务不要指导学生额外连接 UART 设备，也不要把 OLED、DHT、气压、加速度等模块误写成串口模块。

## I2C 共享总线

OLED、DHT20、BMP280、SPA06-003 和 LIS3DHTR 在本课程中都按 I2C 讲解。它们共享 A4/SDA 与 A5/SCL，同一张图中出现多个 I2C 模块时，应同时连到同一组 SDA/SCL 源触点。

I2C 设备地址用于软件寻址，不是接线脚位。本课程资料不把 0x78、0x3C 等地址写成引脚。

## 版本边界

温湿度模块必须区分旧 DHT11 与新 DHT20。版本未知时，网页可以显示模块和提示，但不得固定画成 D3 或 I2C。

气压模块在套件中可能是 BMP280 或 SPA06-003；课程图统一表达为 I2C 接入。某些芯片自身可能支持 SPI，不等于本课程要按 SPI 接线。

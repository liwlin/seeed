# Part2教学素材说明

本目录随V1.0教学材料提供必要配图，服务于硬件认识、Prompt练习和真实验证。图片本身不构成学生成绩、模型返回、程序运行或硬件验收证据。

| 目录 | 图像类型与用途 |
|---|---|
| 课程场景 | 课程方提供的碉楼、创客合作、提示词拼图与闯关地图等概念插画；不是实际学生课堂照片 |
| 课件配图 | PPT使用的官方整板照片裁图、教学接线示意、网页设置及空记录界面 |
| 硬件图 | 官方新版识别照片、官方旧版布局示意、本项目绘制的SVG和PNG板内等效接线图 |
| 硬件图/模块接线细节 | 十个功能模块的接口细节及旧DHT11、未知温湿度版本、旧BMP280参考 |
| 课件预览 | 当前40页PPT的软件渲染预览，文字与表格仍可在PPTX中编辑 |

`网页截图/01_任务引导.png`与`02_提示词学习.png`是实际网页界面，截图时没有配置API Key、调用模型或连接真板。`03_实时接线图.png`由教师模式选择十个模块后从网页实际生成的SVG导出，展示完整模块池，不是M10的预选方案。

硬件照片为静态识别参考，特写清晰度受原图分辨率限制；课堂结合实际开发板观察。旧Parts.jpg是官方布局示意，不是实物照片。新版DHT20与旧版DHT11的接口必须按实板确认，未知版本不猜固定线。

SVG接线图参考Fritzing Breadboard View的视觉表达，由本项目绘制；没有导入Fritzing程序或零件库。图示为完整整板PCB预连接的等效展开，课堂只接USB，不要求拆板外接线。

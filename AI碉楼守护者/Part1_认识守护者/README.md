# Part 1｜认识守护者

**75分钟：碉楼故事与三格图20分钟，Web数字孪生探索55分钟。** 两人一组，先提出一个守护需要，再用真板认识十个硬件伙伴。本部分不讲编程。

课程主体使用 [V1.10.3 Web数字孪生工具](../../web/makerseed_twin_v1_10_3_complete/standalone.html)。老师按随包说明启动本地网页并连接真实 Grove Beginner Kit。网页与 Bridge 的完整运行、依赖、版本关系与测试边界见 [V1.10.3 README](../../web/makerseed_twin_v1_10_3_complete/README.md)。

V1.10.3 的 Part 1 原则：输入类模块以真机数据为证据；LED、蜂鸣器、OLED 可由网页反控实体硬件；温湿度与气压不提供伪造滑条；LIS3DHTR 显示真实 XYZ，并可由学员主动打开“同步实体倾斜姿态”观察 3D 板随重力方向变化。姿态同步默认关闭，三轴加速度计不能单独确定 Yaw / 航向。

## 学员带走什么

- 一张三格图：发生什么、守护者获得什么线索并如何提醒、人怎样回应。
- 十模块观察表：七种输入、三种输出，每项有实际现象或明确缺口。
- 一条输入证据和三条实物输出证据；两人都操作过输入、输出，也记录过同伴实验。
- 两张代表模块卡的解释：功能、碉楼角色、生活案例、当前真值。
- 用真实 XYZ 解释倾斜；打开姿态同步时观察模型如何跟随重力方向，同时明确“倾斜可测、Yaw不可由单纯三轴加速度唯一判断”。
- 留下关输出、断开网页的交接记录。

## 75分钟路线

| 累计时间 | 学习行动 | 分钟 | 页次 |
|---|---|---:|---|
| 00–20 | 碉楼需要、三格故事、守护承诺 | 20 | P1-01–05 |
| 20–31 | 真板与网页、连接定位、输入输出分类 | 11 | P1-06–08 |
| 31–43 | 光线、正常音量说话、旋钮与按键 | 12 | P1-09–10 |
| 43–54 | 两次环境观察、轻倾斜与姿态同步 | 11 | P1-11–12 |
| 54–65 | 网页测试真实LED、短鸣、OLED | 11 | P1-13–15 |
| 65–72 | 扫观察缺口、深读两张卡、解释证据 | 7 | P1-16–17 |
| 72–75 | 关闭输出、断开网页、记录待接管状态 | 3 | P1-18 |
| **合计** | **故事20＋探索55** | **75** | **18页** |

七种输入只能通过真板改变，网页真机读数只读。三种输出通过网页命令测试，必须在实物上看见、听见或读到结果。温湿度、气压可以稳定，但页面应显示真实采样状态而不是模拟滑条。加速度计用于观察重力方向与倾斜姿态；若打开 3D 同步，网页使用 V1.10.3 的坐标映射、Quaternion、低通与当前姿态校准算法，不宣称完整 6DoF 航向跟踪。

今天认识能力，下一课才讨论如何让这些能力按人的规则协作。带上三格图和R7交接记录，设备接管由教师按已验证路径确认；没有确认就标“待确认”。

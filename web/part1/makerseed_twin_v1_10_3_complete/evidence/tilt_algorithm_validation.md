# V1.10.3 LIS3DHTR 倾斜姿态算法验证

## 结论

本版本不再把 LIS3DHTR 当成完整 6/9 轴姿态传感器，而只使用静止/缓动时的重力向量同步 **Pitch / Roll / 正反面倾斜**。绕重力轴的航向 **Yaw 不可由三轴加速度计单独确定**，网页不会伪造该信息。

## 坐标映射

依据用户实物测试照片与屏幕读数，采用：

```text
Sensor X → Model Z（板面上下方向）
Sensor Y → Model X（板面左右方向）
Sensor Z → Model Y（PCB 正面法线）

modelGravity = normalize([sensorY, sensorZ, sensorX])
```

模型默认平放时 `Model +Y` 为 PCB 正面法线。目标 Quaternion 使用：

```text
q = Quaternion.setFromUnitVectors(modelGravity, referenceGravity)
```

默认 `referenceGravity = (0, 1, 0)`。点击“当前姿态设为 0° 倾斜基准”后，参考向量改为当前重力向量，因此当前姿态立即成为视觉零倾斜。

## 数值验收

自动化测试对上述每组数据执行：

1. 轴映射 `(X,Y,Z) → (Y,Z,X)`；
2. 向量归一化；
3. `setFromUnitVectors(mappedGravity, referenceGravity)`；
4. 用所得 Quaternion 旋转原映射向量；
5. 检查旋转后向量与参考重力方向夹角。

验收阈值：残差 `< 0.0001°`。测试结果见 `tilt_browser_qa.json`。

## 低通滤波

使用一阶指数低通：

```text
alpha = 1 - exp(-dt / 90 ms)
filtered = normalize(lerp(filtered, sample, alpha))
```

在 20 Hz（50 ms/帧）状态流下，约 150 ms 可完成超过 80% 的阶跃响应，兼顾手持稳定与实时性。

## 动态加速度保护

当加速度合量不在 `0.55–1.45 g` 内时，本帧不用于更新 3D 倾斜姿态，避免快速移动、甩动或碰撞把线性加速度误当重力方向。界面仍显示原始 XYZ 和“运动干扰较大”。

## Yaw 不可观测证明

当某个 Quaternion 已把测得的重力向量对齐到世界竖直方向后，再叠加任意绕世界竖直轴的旋转，重力方向仍保持不变。因此仅凭三轴加速度无法唯一解出航向角。自动化测试 `test_yaw_is_mathematically_underdetermined_from_gravity_only` 对此进行了数值验证。

## 验收边界

- 能验证：静止/缓动下的倾斜方向、俯仰/横滚、正反面。
- 不宣称：完整 6DoF 姿态、航向、持续旋转积分。
- 若未来需要完整姿态，应换用带陀螺仪的 6 轴 IMU（再做融合算法）。
